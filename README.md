# film_catalog
Консольное приложение для ведения личной базы данных просмотренных фильмов с оценками. Аналог упрощенной версии IMDb или Кинопоиска.

Функциональность:

Добавление фильмов с информацией: название, режиссер, год выпуска, жанр, личная оценка (1-10)
Поиск и фильтрация фильмов по названию, жанру или рейтингу
Редактирование информации о фильмах, включая изменение оценки
Топ фильмов - просмотр списка фильмов, отсортированного по оценке
Сохранение данных между запусками приложения

Функциональность при запуске:

1. Добавить фильм - ввод информации о новом фильме
2. Показать все фильмы - просмотр полного каталога
3. Найти фильм - поиск по названию
4. Фильтровать по жанру - отбор фильмов по жанру
5. Фильтровать по рейтингу - отбор фильмов с оценкой выше указанной
6. Топ фильмов - просмотр фильмов, отсортированных по оценке
7. Редактировать фильм - изменение информации о фильме
8. Удалить фильм - удаление фильма из каталога
9. Выход - сохранение данных и завершение работы
